# ADR-001 — Microsserviços como laboratório
Status: aceito para formação; não é requisito do desafio.

## Contexto
O desafio oficial pede um serviço de anúncios. O objetivo educacional é exercitar trade-offs de Senior/Lead/Architect.

## Decisão
Monorepo com deploys e contratos separados para Ads Command, Moderation Worker e Ads Query. Ads Command e Moderation Worker mantêm bancos lógicos próprios; OpenSearch e Redis são projeção/cache, não fontes transacionais. Kafka e Outbox estão implementados na versão Enterprise. `solutions/simple` é a aplicação separada e síncrona para o contrato oficial.

## Consequências
Maior custo operacional, consistência eventual, contratos distribuídos, observabilidade e testes de integração necessários. Não interpretar arquitetura complexa como prova de escala real; adotar somente quando requisito e medição justificarem.
